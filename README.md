# iFatima-s_Interactive_Portfolio 
**(also known as the 2D Game Portfolio)**

An interactive 2D game created with Unity to showcase my skills in terms of game development & pixel art.

---

## Features

* **Item Interaction** - Clean, highlighted, easy to navigate
* **Map** - Easy to understand & read
* **System Settings** - To turn the music & interaction noises on or off
* **Starting Page** - To navigate through the game or other available options, including instructions on how to play
* **Full Screen & Music** - To enhance the user experience
* **Dialog Box** - To help deliver the meaning behind my portfolio
* **Working rerouting Links** - For when the visitor is interested
* **Unity UI** - For ideal usability with in-built modeling

---

## 📦 Tech Stack

* **Frontend:** Unity
* **Code Formatting:** C#
* **Art:** Gimp
* **Deployment:** Itch.io (optional)
